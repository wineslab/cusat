# Deployment

The supported deployment paths are grouped first by deployed system and then
by environment:

- `cusat/docker/`: standalone cuSAT NVIDIA image and Docker Compose workflow.
- `cusat/kubernetes/`: standalone cuSAT OpenShift manifests and GH200 release
  workflow.
- `cusat-mobile-backhaul/`: cuSAT plus OAI mobile-backhaul Docker images and
  runtime (see the [OAI backhaul tutorial](../docs/tutorials/03-oai-backhaul.md)).

The platform setup and canonical operator guides are indexed from
[`docs/index.md`](../docs/index.md).
