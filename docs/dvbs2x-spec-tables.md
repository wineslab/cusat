## A. APSK Constellation Definitions (clause 5.4.x)

For ring-ratio tables the convention is: ring radii are `R1, R2, ...` and the
γ values are defined per the table header (e.g. `γ1 = R2/R1`). Set `R1 = 1` for a
nominal (unnormalized) constellation, then power-normalize over all 64/128/256 points.

The angle convention: each row gives the label and its ring `R`, and the phase
`φ` is read from the `φ/π` column for the relevant `(p, q)` sub-case. The point is
`R · exp(j·φ)`. The leading label bits select the `(p, q)` / sub-table column; the
trailing bits select the row.
